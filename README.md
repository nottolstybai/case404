# case404

Ежедневное «Дело №…»: ночью в старый дом пришли пятеро. По уликам найди преступника — кто он, когда пришёл, где был и что при нём нашли. Одно дело в день, ответ всегда один.

**Играть:** https://nottolstybai.github.io/case404/

Локально: `python3 -m http.server 8765` · тесты: `npm test` · перед пушем: `npm run stamp`

# case404

Ежедневное «Дело №…»: ночью в старый дом пришли пятеро. По уликам восстанови хронику ночи и найди преступника — кто он, когда пришёл, где был и что при нём нашли. Одно дело в день для всех, ответ всегда один; сверх того — случайные дела по коду (`?case=x-…`). Все дела собирает генератор из случайного расклада.

**Играть:** https://nottolstybai.github.io/case404/

Локально: `python3 -m http.server 8765` · тесты: `npm test` · перед пушем: `npm run stamp`

Музыка и звуки действий синтезируются в браузере (`src/audio.js`), файлов нет.

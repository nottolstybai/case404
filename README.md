# case404

Ежедневное «Дело №…»: ночью в старый дом пришли пятеро. По уликам восстанови хронику ночи и найди преступника — кто он, когда пришёл, где был и что при нём нашли. Одно дело в день для всех, ответ всегда один; сверх того — случайные дела по коду (`?case=x-…`). Все дела собирает генератор из случайного расклада.

**Играть:** https://nottolstybai.github.io/case404/

Локально: `python3 -m http.server 8765` · тесты: `npm test` · перед пушем: `npm run stamp`

**Прототип нового режима «показания»** — `proto.html`: преступник лжёт в каждой фразе, невиновные говорят правду; найди лжеца по противоречиям, переверни его ложь и узнай о нём всё. Генератор — `src/testimony.js`. Трудные дела собираются долго, поэтому дела дня заготовлены заранее в `cases/testimony/` (`npm run cases` — от вчера на 45 дней; пересобирать после правок генератора). Дело текстом для плейтестов: `node scripts/case.mjs testimony 2026-12-05`.

**То же в 3D-кабинете** — `proto3d.html`: дело открывается видом от первого лица — садишься за стол с лампой, камера опускается к бумагам и переходит в ту же 2D-игру (листы на 3D-столе рисуются с экрана, `src/paint.js`); кнопка с лампой в шапке — обратно за стол; в конце рука ставит на протокол штамп «Раскрыто» или «Не раскрыто». Кабинет — `src/office3d.js`, Three.js облегчён до нужных классов в `vendor/three.js` (`node scripts/vendor-three.mjs`). Нет WebGL — играется как обычный прототип.

Музыка и звуки действий синтезируются в браузере (`src/audio.js`). Исключение — карандаш: ✗ и ✓ звучат записью штрихов по бумаге (`sfx/`, CC0, источник и обработка — в `sfx/CREDITS.md`); пока записи не загрузились, звучит синтез.

# case404 — «Дело №…»

Ежедневная логическая загадка в духе тру-крайма. Ночью в старый дом пришли пятеро. У каждого — своё время прихода, своё место и вещь, которую при нём нашли. По уликам нужно понять, кто преступник, и выдвинуть полное обвинение.

- одно дело в день, одинаковое у всех (зависит только от даты);
- ответ всегда один, и до него можно дойти логикой — генератор это проверяет решателем и полным перебором;
- для ответа нужно не меньше 75% улик, остальные — ложные следы;
- всё работает в браузере, без сервера.

## Запуск

```sh
python3 -m http.server 8765   # открыть http://localhost:8765
```

Любое дело можно открыть по дате: `?date=2026-11-21`.

## Тесты и публикация

```sh
npm test         # Node 20+
npm run stamp    # перед коммитом: отпечатки файлов в index.html, чтобы кэш GitHub Pages не смешал версии
```

## Устройство

| файл | что внутри |
|---|---|
| `src/daily.js` | дата → дело дня |
| `src/generator.js` | раскладка, подбор улик, выбор преступника и сложности |
| `src/logic.js` | решатель, который рассуждает как человек (для подсказок и генератора) |
| `src/brute.js` | полный перебор: проверка, что ответ не виден слишком рано |
| `src/puzzle.js`, `src/suspects.js` | комнаты, предметы, подозреваемые |
| `src/text.js` | тексты улик и истории по-русски |
| `src/game.js` | отметки, отмена, подсказка, обвинение |
| `src/main.js`, `style.css` | экран |
| `src/art.js` | картинки: силуэты подозреваемых, дом на холме, штамп |

Все персонажи вымышлены.
